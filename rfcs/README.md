# RFCs do Fin+

Cada mudança não trivial no projeto (nova funcionalidade, melhoria, refatoração, integração) passa por uma RFC antes de qualquer implementação, seguindo o protocolo definido em [`CLAUDE.md`](../CLAUDE.md).

- Nome do arquivo: `RFC-NNN-titulo-curto.md`, numeração sequencial.
- Uma RFC nasce com status `proposta`, evolui para `em andamento` conforme passa pelas etapas do Workflow Oficial, e termina `concluída` (ou `rejeitada`, se abandonada).
- O registro por etapa (Product Owner → Software Architect → ... → DevOps) fica dentro do próprio arquivo da RFC — não é espalhado em outros lugares.
